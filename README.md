# protolude1
## Le but du jeu est d'amasser des ressources afin de se forger une épée.
1. Vous rendre à l'arbre avec le cone et appuyez 'E' afin de couper l'arbre.
2. Vous rendre au kiosque avec le cone, où vous aller acheter un lingot de fer (toujours appuyez 'E')
3. Vous rendre au kiosque de forgerie (passez la rivière dans les bois) et appuyez 'E' pour forger votre épée.

Attention de ne pas rester trop longtemps dans la brume mystérieuse du cimetière...

La sphère proche du cimetière est affecté par la gravité.
